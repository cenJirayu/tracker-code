Mission Monitor

Running these: open this file directly in Chrome or Edge — they use the Web Serial API (unavailable in Firefox/Safari). Everything is self-contained: no internet, no server, no install. Connect to the ESP32-S3 over USB at 115200 baud. The JSON protocol both panels speak is documented in PROTOCOL.md.
